# 分流标签规范 (Triage Labels)

相关技能基于 5 个标准分流角色进行调度。本文件将这些抽象角色映射到本仓库 Issue 跟踪器中实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | 含义说明                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 待维护者评估与分流                        |
| `needs-info`               | `needs-info`         | 待反馈，等待提交者提供更多信息            |
| `ready-for-agent`          | `ready-for-agent`    | 规格完备，可由自主 Agent 全自动实现       |
| `ready-for-human`          | `ready-for-human`    | 需要人工开发者介入实现                    |
| `wontfix`                  | `wontfix`            | 不予处理 / 关闭                           |

当技能提及某一角色时（例如“应用就绪分流标签”），请使用本表格中对应的标签字符串。

如需映射本仓库实际使用的其它标签命名，可直接修改第二列（`Label in our tracker`）。
